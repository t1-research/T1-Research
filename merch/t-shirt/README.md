# T-Shirt

All prints are 600 DPI transparent PNGs. Files without `-light` are white/teal
art for dark shirts; `-light` files are navy art for light shirts. ProRIP
mirrors automatically — load the print files as-is.

## Prints

| Placement | Dark garment | Light garment | Size |
| --- | --- | --- | --- |
| Front chest (left chest) | `t1-shirt-front-600dpi.png` | `t1-shirt-front-600dpi-light.png` | 4" x 4" |
| Full front (What We Do) | `t1-shirt-front-full-600dpi.png` | `t1-shirt-front-full-600dpi-light.png` | 12" x 12" |
| Back (contact info) | `t1-shirt-back-600dpi.png` | `t1-shirt-back-600dpi-light.png` | 12" x 12" |

## Alternates

- `t1-wordmark-lockup-print.png` — alternate back design (white/teal T1
  lockup, 3200 x 3200 transparent).
- `t1-badge-emblem-print.png` — alternate chest design, Walton County badge
  (navy art on transparent, best on light garments, 3200 x 3200).

## Previews

The `*-preview.jpg` files show each design on navy. The transparent print
files look blank against a white background, so use the previews to see what
you're printing.
