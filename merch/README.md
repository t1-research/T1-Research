# T1 Research & Development — Merch

Print-ready designs, organized by product. Each folder is self-contained: the
print files, a preview you can actually see, and a mockup of the finished
product.

## Folders

- `t-shirt/` — front chest, full front, and back prints (dark + light garments)
- `hoodie/` — same prints as the t-shirt, with hoodie mockups
- `tumbler/` — 20 oz full wrap
- `mug/` — 11 oz wrap band
- `hat/` — no design yet (placeholder)

## Print notes

- Shirt prints are 600 DPI transparent PNGs. Files without `-light` are
  white/teal art for dark garments; `-light` files are navy art for light
  garments.
- The transparent print files look blank against a white background — use the
  `*-preview.jpg` files (on navy) to see what the design is.
- ProRIP mirrors automatically for transfer paper, so load the print files
  as-is. Do not mirror them yourself.
- Tumbler and mug wraps are full-bleed RGB designs for sublimation.
